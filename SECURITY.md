# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it privately to the repository owner.

Do not disclose security vulnerabilities publicly through GitHub Issues before they have been reviewed.

When reporting a vulnerability, include:
- A description of the issue.
- Steps to reproduce it, if possible.
- The potential impact.

## Supported Versions

Only the latest version of the project is currently supported with security updates.

## Security Updates

Dependencies are monitored using GitHub Dependabot.

Security updates will be reviewed before merging. Changes will be tested to reduce the risk of introducing regressions.

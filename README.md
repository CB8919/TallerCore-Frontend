# 🚗 TallerCore — Frontend

Frontend de **TallerCore**, un sistema de gestión para talleres mecánicos desarrollado como proyecto académico propio.

La aplicación permite gestionar las principales operaciones del taller y se encuentra actualmente en **desarrollo activo**.

---

## ✨ Funcionalidades actuales

* 🔐 Inicio de sesión y autenticación
* 👤 Registro de clientes
* 🚗 Registro de vehículos
* 📝 Creación de órdenes de trabajo
* 📊 Panel de control
* 🔗 Comunicación con la API REST del backend

---

## 🛠️ Tecnologías

* ⚛️ **React**
* 📘 **TypeScript**
* 🎨 **Tailwind CSS**
* ⚡ **Vite**

---

## 🚀 Instalación

Clonar el repositorio:

```bash
git clone https://github.com/CB8919/TallerCore-Frontend.git
cd TallerCore-Frontend
```

Instalar las dependencias:

```bash
npm install
```

Crear el archivo de variables de entorno:

```bash
cp .env.example .env
```

Iniciar el servidor de desarrollo:

```bash
npm run dev
```

---

## 🔌 Backend

El frontend se comunica con una **API REST desarrollada con Java y Spring Boot**.

> El repositorio del backend es privado.
